# Smart Taxi API 🚖

Smart Taxi API is an intelligent web service for estimating taxi trip costs. It uses a Machine Learning model to predict the estimated fare based on trip distance and traffic conditions, with optional LLM and TTS integration for natural-language explanations and audio output.

## Installation

Clone the repository:

```bash

cd smart-taxi-api
```

```bash
pip install -r requirements.txt
```
